# Product Roadmap — Analytics Platform

## Phase 1: MVP (Текущий)

**Цель:** Рабочая платформа с базовой аналитикой

### Реализовано
- [x] Аутентификация (JWT + invite links)
- [x] Роли: admin / editor / viewer
- [x] Загрузка CSV файлов
- [x] История импортов с статусами
- [x] Хранение исторических данных
- [x] Защита от дублирования (SHA256)
- [x] Дашборд с KPI карточками
- [x] Графики: line, bar, area
- [x] Фильтрация: даты, гранулярность, метрики
- [x] Управление пользователями
- [x] Управление источниками данных
- [x] Реестр метрик с русскими названиями
- [x] Русскоязычный интерфейс
- [x] Печатная версия (@media print)
- [x] Docker Compose setup
- [x] Seed / demo data
- [x] Schema-driven расширяемая архитектура

---

## Phase 2: Расширенная аналитика (Q2-Q3 2025)

**Цель:** Углублённые аналитические возможности

### Новые типы отчётов
- [ ] Когортный анализ (retention cohorts)
- [ ] Воронки конверсий (funnel analysis)
- [ ] Сравнение периодов (period-over-period)
- [ ] Накопительные суммы (cumulative metrics)

### Новые источники данных
- [ ] Аналитика по тарифам
- [ ] Источники трафика
- [ ] Конверсии по шагам

### Улучшения дашбордов
- [ ] Drag & drop редактор виджетов
- [ ] Кастомные размеры виджетов (grid layout)
- [ ] Сохранение пресетов фильтров
- [ ] Экспорт графика как PNG/SVG

---

## Phase 3: Совместная работа (Q3-Q4 2025)

**Цель:** Командная работа с данными

### Доступы
- [ ] Шаринг отдельных дашбордов (по ссылке, без логина)
- [ ] Комментарии к виджетам
- [ ] Аннотации на графиках (события)

### Уведомления
- [ ] Email-рассылка дашбордов (расписание)
- [ ] Алерты при отклонении метрик

### Экспорт
- [ ] Экспорт данных в Excel / CSV
- [ ] Экспорт дашборда в PDF через headless browser
- [ ] Scheduled reports (PDF по расписанию)

---

## Phase 4: Multi-workspace (2026)

**Цель:** Поддержка нескольких проектов в одной платформе

### Архитектура
- [ ] Organizations / Workspaces
- [ ] Изоляция данных между workspace
- [ ] Billing (если нужен SaaS-режим)

### Управление данными
- [ ] Data catalog (каталог всех источников)
- [ ] Data lineage (откуда пришли данные)
- [ ] Schema versioning (версии схем)

---

## Phase 5: AI Insights (2026+)

**Цель:** Автоматические инсайты и аномалии

### AI функции
- [ ] Автоматическое обнаружение аномалий
- [ ] Предсказание трендов (forecasting)
- [ ] Автоматические инсайты ("В январе выручка выросла на X% из-за...")
- [ ] Natural language queries ("Покажи выручку за прошлый месяц")
- [ ] Автоматическая генерация отчётов

---

## Assumptions & Constraints

- MVP рассчитан на команду 1-10 человек
- Данные обновляются вручную (CSV upload), не real-time
- Все данные — агрегированные (не сырые события)
- Платформа русскоязычная для русскоязычной команды
- Horizontal scaling не требуется для MVP

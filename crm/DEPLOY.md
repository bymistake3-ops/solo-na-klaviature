# 🚀 Как развернуть EduCRM с нуля — пошаговая инструкция

Для того, кто **никогда не работал с GitHub и деплоем**. Всё будет через браузер, без терминала и без кода.

В конце у тебя будет:

- ✅ Рабочая CRM по адресу вида `твоё-имя-crm.vercel.app`
- ✅ Бесплатная PostgreSQL-база данных (Neon)
- ✅ Бесплатный хостинг (Vercel)
- ✅ Возможность пригласить сотрудника

**Время: ~30 минут. Стоимость: 0₽.**

---

## Что тебе понадобится

1. Рабочий email
2. Желательно — аккаунт Google (чтобы быстро логиниться везде через «Войти через Google»)
3. ~30 минут спокойного времени

---

## Шаг 1. Создать аккаунт GitHub (3 мин)

GitHub — это «облако для кода». CRM живёт там, а Vercel умеет её оттуда забирать.

1. Открой **https://github.com** → нажми **Sign up**
2. Введи email, пароль, придумай username (например, `anna-edtech`)
3. Подтверди email через письмо от GitHub
4. На экране «Welcome» пропускай все анкеты — нажимай «Skip»

> 💡 Твоё имя пользователя в GitHub будет частью адресов. Выбери простое: `anna`, `edtech-anna`, `annacrm`.

---

## Шаг 2. Сделать свою копию CRM (2 мин)

Сейчас код CRM лежит в чужом репозитории. Нужна твоя собственная копия — она называется **форк**.

1. Открой репозиторий с CRM: **https://github.com/bymistake3-ops/solo-na-klaviature**
   *(если у тебя другой URL — используй его)*
2. В правом верхнем углу нажми **Fork** (рядом с «Watch» и «Star»)
3. На следующем экране ничего не меняй — просто нажми зелёную кнопку **Create fork**
4. Через ~5 секунд ты окажешься в своей копии. Адрес будет вида:
   `https://github.com/ТВОЙ_USERNAME/solo-na-klaviature`

Держи эту вкладку открытой — адрес понадобится.

---

## Шаг 3. Создать базу данных Neon (5 мин)

Neon — бесплатный PostgreSQL в облаке. Free-плана хватит на много лет небольшой команде.

1. Открой **https://neon.tech** → **Sign up**
2. Выбери вход **через GitHub** (проще всего)
3. После входа Neon сам предложит создать первый проект:
   - **Project name**: `educrm`
   - **Postgres version**: оставь по умолчанию
   - **Region**: выбери ближайший (`Europe (Frankfurt)` для России/ЕС)
   - Нажми **Create project**
4. Ты попадёшь на страницу проекта. В центре будет блок **Connection string**:
   - Формат: `postgresql://user:password@ep-xxx.neon.tech/neondb?sslmode=require`
   - Нажми иконку копирования 📋 справа от строки
5. **Сохрани эту строку** в заметки — она понадобится на шаге 5.

> ⚠️ Эта строка — как пароль к твоей базе. Никому не показывай и не публикуй в интернете.

---

## Шаг 4. Сгенерировать секрет для сессий (30 сек)

CRM использует секретный ключ, чтобы подписывать cookies пользователей.

1. Открой **https://generate-secret.vercel.app/32**
2. Увидишь длинную случайную строку — скопируй её
3. **Сохрани в заметки** рядом со строкой из шага 3

Должно получиться что-то вроде:

```
DATABASE_URL = postgresql://neondb_owner:xxxx@ep-xxx.neon.tech/neondb?sslmode=require
AUTH_SECRET  = 7b3f9a2c4e5d1f8a6b3c7e9d2f4a6c8e
```

---

## Шаг 5. Развернуть на Vercel (10 мин)

Vercel — хостинг для Next.js сайтов. Для нашей CRM free-плана хватит с запасом.

### 5.1. Регистрация

1. Открой **https://vercel.com/signup**
2. Выбери **Continue with GitHub** (Vercel попросит разрешение — дай его)

### 5.2. Импорт проекта

1. После регистрации на главной нажми **Add New...** → **Project**
2. Появится список твоих репозиториев GitHub. Найди `solo-na-klaviature` и нажми **Import** напротив него

### 5.3. Настройка проекта (самое важное!)

Ты окажешься на экране **Configure Project**. Здесь нужно сделать 3 вещи:

**(1) Project Name** — можешь оставить как есть или поменять на что-то короткое, например `educrm`. Это будет частью URL.

**(2) Root Directory** — КРИТИЧЕСКИ ВАЖНО:

- Нажми кнопку **Edit** справа от «Root Directory»
- В открывшемся окне найди и выбери папку `crm`
- Нажми **Continue**

Должно стать: `Root Directory: crm`

**(3) Environment Variables** — добавь 2 переменные:

Раскрой блок **Environment Variables** и добавь по одной:

| Name | Value |
|------|-------|
| `DATABASE_URL` | *строка подключения Neon из шага 3* |
| `AUTH_SECRET` | *секрет из шага 4* |

Для каждой: введи имя, вставь значение, нажми **Add**.

### 5.4. Деплой

1. Нажми большую кнопку **Deploy** внизу
2. Появится экран сборки — процесс занимает ~2–3 минуты
3. Когда увидишь салют 🎉 и надпись **Congratulations!** — сайт готов
4. Нажми на превью или кнопку **Continue to Dashboard**

### 5.5. Открыть CRM

1. На дашборде Vercel найди блок **Domains** — там будет ссылка вида `educrm-xxxxx.vercel.app`
2. Открой её в новой вкладке

---

## Шаг 6. Создать первого админа (1 мин)

При первом открытии CRM ты увидишь экран **«Первый запуск»**.

1. Введи своё имя (например, «Анна Иванова»)
2. Свой email
3. Пароль (минимум 6 символов) — **запомни его!**
4. Нажми **Создать аккаунт и войти**

Ты попадёшь на дашборд. Поздравляю — CRM работает в проде! 🎉

---

## Шаг 7. Пригласить сотрудника (30 сек)

1. В левом меню кликни **Команда**
2. Заполни форму «Добавить участника»:
   - Имя сотрудника
   - Его email
   - Временный пароль (любой, минимум 6 символов)
   - Роль: **member** (или **admin**, если хочешь дать полные права)
3. Нажми **Пригласить**
4. Отправь сотруднику:
   - ссылку на твою CRM
   - его email и пароль
   - попроси сменить пароль (*пока этой функции нет — на втором этапе добавим*)

## ✅ Готово! Что делать дальше

### Как добавлять клиентов

- **B2C клиент:** в меню «B2C клиенты» → «+ Добавить клиента»
- **B2B компания:** «B2B аккаунты» → «+ Добавить компанию»
- **Задача:** «Задачи» → ввести текст в поле сверху

### Как обновлять CRM (когда появятся новые фичи)

Если захочешь обновить код на новую версию:

1. Открой свою копию репозитория на GitHub
2. Если появились обновления — увидишь кнопку **Sync fork** → нажми её
3. Vercel автоматически пересоберёт сайт за 2 минуты

Больше ничего не нужно — обновления прилетают сами.

## ❓ Частые вопросы

### Сколько это всё стоит?

На текущих объёмах (небольшая команда) — **0₽**:

- **Vercel Free**: 100 ГБ трафика, неограниченные деплои
- **Neon Free**: 0.5 ГБ базы, хватит на 10–20 тысяч клиентов
- **GitHub Free**: неограниченные публичные репозитории

Когда вырастешь — первый платный уровень начинается от $19/мес на каждый сервис.

### Что если я забуду пароль?

Пока нет функции восстановления. Варианты:

1. Попроси другого админа удалить твой аккаунт через «Команда» и создать заново
2. Если админ один — напиши мне, я подскажу, как сбросить через Neon

### Что если CRM сломается?

В Vercel на вкладке **Deployments** всегда можно откатиться на прошлую рабочую версию:
«…» → **Promote to Production**.

### Можно ли экспортировать данные?

Да. В Neon есть встроенный экспорт всей базы в файл (**Dashboard → Backups**).

### А если хочу свой домен (например, crm.myschool.ru)?

В Vercel: **Project → Settings → Domains → Add**. Дальше нужно будет прописать одну DNS-запись у регистратора домена. Это ещё 10 минут — могу написать инструкцию отдельно.

## 🆘 Если что-то пошло не так

**Build failed** на Vercel:
→ В логах деплоя ищи красную строку с ошибкой. Чаще всего — неправильный `DATABASE_URL`. Проверь в Vercel: **Project → Settings → Environment Variables**.

**Ошибка «Can't reach database»:**
→ Строка подключения Neon могла скопироваться с пробелом или без `?sslmode=require` в конце. Скопируй заново.

**Login не работает после первого создания админа:**
→ Скорее всего забыл пароль. Сбрось через Neon: **Project → Tables → User → Delete row → Обнови страницу CRM → Создай админа заново**.

**Не нашёл папку `crm` при импорте в Vercel:**
→ Убедись, что сделал **fork** правильного репозитория (шаг 2) и там есть папка `crm/`.

Если застрял на каком-то шаге — опиши, что видишь на экране, и я подскажу.
